# SOP-08 — HR Module

**Version**: 1.0
**Module**: HR
**Status**: Active

---

## Purpose
Manage Myers Digital's people operations — contractors, hiring, onboarding, performance, and team health.

## Trigger
Any directive involving team members, contractors, hiring, or organizational health.

## Contractor Onboarding (HR-SOP-01)
1. Dustin approves new contractor role via Director
2. `HR-01` Zapier fires: post role in contractor networks
3. Applications received → scored against requirements
4. Dustin reviews top candidates
5. Offer extended → contractor agreement executed (Legal Module)
6. `HR-03` Zapier fires: onboarding checklist created
7. Contractor added to:
   - Notion Client Registry (as team member)
   - Relevant Slack channels
   - GHL access (appropriate level)
   - Tool stack access

## Contractor Performance Review (HR-SOP-02)
Monthly:
1. Review delivery metrics for each contractor
2. Score: on-time delivery, client feedback, communication
3. Flag any contractor with score < 3.5/5
4. Route flags to Dustin with recommendation

## Offboarding (HR-SOP-03)
1. Dustin confirms offboarding
2. Revoke all access: GHL sub-accounts, Notion, Slack, tools
3. Transfer active client projects to remaining team
4. Document knowledge in Notion SOP Library
5. Exit interview notes logged
