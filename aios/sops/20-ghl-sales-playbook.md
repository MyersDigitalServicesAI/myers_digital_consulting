## THE MASTER SALES SCRIPT

### The Discovery Open
> "Let me ask you something directly — when a new lead comes in right now, what actually happens next? Walk me through it step by step."

Listen for: manual steps, delays, dependency on one person, things that "sometimes" get done. Every pause and "it depends" is a gap you can systematize.

### Quantify the Problem
> "So if I'm understanding correctly — every lead depends on [specific person] remembering to [specific action] within [specific window]. What happens when that doesn't happen? How often does that happen in a week?"

**Calculate out loud**: 3 missed leads/day × $400 avg → $1,200/day → $36,000/month → $432,000/year. Say the number.

### The Solution Frame
> "Here's what we're going to build for you — a revenue automation system that eliminates every one of those gaps. Every lead gets an immediate response. Every appointment gets confirmed and reminded. Every happy customer gets asked for a review. Every cold contact gets a reactivation campaign. And you have a real-time dashboard showing exactly how your business is performing. This isn't software. This is growth infrastructure."

### The Future Picture
> "Three months from now, you're not chasing leads — leads are being chased automatically. You're not wondering if someone followed up — it happened at 60 seconds. You're not losing jobs to competitors who answer faster — because your system answers faster than any human can. The business runs. You grow."

## THE 17 GHL TOOLS

### 1. CRM & Pipelines
**Problem**: Leads fall through cracks. Owners use spreadsheets, sticky notes, or memory.  
**Cost**: Every untracked lead = $500–$5,000 gone dark.  
**Sales angle**: "Business Command Center — the single source of truth that replaces scattered notes with a revenue-tracking machine."  
**Setup**: Create sub-account → Define pipeline stages → Set custom fields → Import contacts → Configure smart lists → Enable team notifications → Connect lead sources

### 2. Lead Capture Funnels
**Problem**: Traffic goes to a generic website that doesn't convert.  
**Cost**: $1,000/mo ad spend + no funnel = $0 in trackable leads.  
**Sales angle**: "The Conversion Engine that makes every dollar of ad spend accountable."  
**Setup**: Choose template → Write headline/offer → Build 2-step form → Set thank-you page → Connect to CRM → Enable instant notification → Add calendar option

### 3. Automated SMS Follow-Ups
**Problem**: Follow-up is inconsistent — some leads called in an hour, others wait 3 days.  
**Cost**: 78% of deals go to first responder. 5-min response converts 10x better than 30-min.  
**Sales angle**: "Speed-to-Lead System — your competitor texts first, you lose. This makes sure you're always first."  
**Setup**: Define trigger → Write 6-touch SMS sequence → Add personalization → Set conditional logic → Add human handoff → Test → Launch

### 4. Email Automation
**Problem**: One email blast per quarter. No nurture, no onboarding cadence.  
**Cost**: 2,000-contact list with no automation = $0. With a sequence = $20K–$80K/year reactivated.  
**Sales angle**: "Dormant Revenue Activator — email is the highest-ROI channel for owned audiences."  
**Setup**: Audit list → Map client journey → Write sequences → Design templates → Set triggers → Configure timing → Enable tracking

### 5. Missed Call Text-Back
**Problem**: Phone rings while owner is on a job. Caller gets voicemail, calls competitor.  
**Cost**: 3 missed calls/day × $600 avg = $1,800/day in lost revenue.  
**Sales angle**: LIVE DEMO — call the demo number, let it ring, show text arriving in 60 seconds. Sells itself.  
**Setup**: Connect business number → Create missed call trigger → Write SMS → Enable AI conversation → Set qualification questions → Route hot leads → Set follow-up

### 6. Appointment Booking Calendars
**Problem**: Booking is a manual bottleneck. No-show rates are high.  
**Cost**: 30% no-show rate on $400-avg service × 4 appts/day = $480/day lost.  
**Sales angle**: "Your 24/7 receptionist that never calls in sick and never forgets to send a reminder."  
**Setup**: Create calendar → Set availability → Embed or share → Build confirmation sequence → Build reminder (24h, 2h, 1h) → Create no-show re-booking → Add post-appointment follow-up

### 7. Reputation Management
**Problem**: 12 Google reviews from 4 years ago. Competitors have 200+.  
**Cost**: 4.8 stars + 100 reviews wins 3x more clicks than 3.9 stars + 15 reviews.  
**Sales angle**: "Your happiest customers just need to be asked at exactly the right moment — and we automate that."  
**Setup**: Connect GBP → Create post-job trigger → Write review request SMS → Add email backup → Set 48-hour follow-up → Configure reputation dashboard → Set low-review alert

### 8. Forms & Surveys
**Problem**: Generic contact form. No qualification. No feedback loop.  
**Cost**: 2 hours on a quote for unqualified prospect = $200–$500 wasted productivity.  
**Sales angle**: "Intelligent Intake System — qualifies leads before they ever reach you."  
**Setup**: Define intake data → Build form with conditional logic → Map to CRM → Create post-service survey → Trigger follow-up based on score → Build reporting dashboard

### 9. Sales Funnels
**Problem**: No structured path from interested to purchased.  
**Cost**: 1-3% conversion vs. 8-15%+ with a proper funnel = 3x–10x more revenue from same traffic.  
**Sales angle**: "Your digital sales rep — presents, persuades, and converts at any hour without a human in the room."  
**Setup**: Map offer and audience → Build awareness page → Create offer page → Add urgency → Build order form with bump → Create upsell/downsell → Set confirmation sequence

### 10. Membership Sites
**Problem**: Same content delivered over and over in 1-on-1 calls. Time caps revenue.  
**Cost**: $200/session × 40 hrs/week = $8K/month ceiling. Membership: 500 members × $97 = $48.5K/month.  
**Sales angle**: "Your knowledge already exists. We turn it into a product that sells while you sleep."  
**Setup**: Define structure → Upload content → Connect Stripe → Build sales page → Set drip delivery → Create onboarding sequence

### 11. Workflow Automation
**Problem**: Every manual step is a point of failure. Things fall through cracks.  
**Cost**: Can't scale 50 to 200 clients with manual workflows — missed follow-ups, owner burnout.  
**Sales angle**: "The system that runs your business when you're not in it."  
**Setup**: Audit manual processes → Map top 3 workflows → Build lead intake flow → Build appointment → confirmation → post-visit flow → Build job complete → invoice → payment flow → Test → Train team

### 12. Lead Nurture Campaigns
**Problem**: Leads that say "not now" are never contacted again.  
**Cost**: 70% of leads who don't buy immediately will eventually buy from whoever stays in front of them.  
**Sales angle**: "You're sitting on a gold mine of leads that already know you."  
**Setup**: Segment "not ready" bucket → Define nurture goal → Build 30-day sequence → Write value-first content → Add trip-wire offer at Day 14 → Set conditional exits → Track conversion

### 13. AI Conversation Management
**Problem**: Leads message after hours and get no response.  
**Cost**: 5-minute response converts 21x better than 30-minute. After-hours = 90% abandonment without AI.  
**Sales angle**: LIVE DEMO — set up AI persona, show it handling a real conversation and booking an appointment in real time.  
**Setup**: Define AI persona → Write system prompt → Load FAQ knowledge base → Build qualification sequence → Connect to calendar → Set escalation triggers → Test 20+ scenarios

### 14. Call Tracking
**Problem**: Spending on 3-4 marketing channels with no idea which produces revenue.  
**Cost**: Average waste on untracked budgets: 30-50% of spend going to wrong channels.  
**Sales angle**: "Marketing Accountability System — do you know which dollar is generating the most revenue?"  
**Setup**: Audit marketing channels → Create unique GHL numbers per channel → Configure call forwarding → Enable recording/transcription → Set missed call workflows → Build reporting dashboard → Monthly review

### 15. Analytics Dashboards
**Problem**: Making decisions without data. Don't know lead-to-close rate, CAC, or which rep performs best.  
**Cost**: Businesses without data plateau — can't identify bottlenecks, can't reward top performers.  
**Sales angle**: "Your business's control panel." Use the dashboard as a retention tool — clients who see results monthly stay longer.  
**Setup**: Identify 5-10 critical KPIs → Build custom dashboard → Connect CRM + call data → Include revenue tracking → Set up automated weekly email → Schedule monthly review call

### 16. Database Reactivation Campaigns
**Problem**: Hundreds of past contacts who said "not now" — never followed up.  
**Cost**: 7x more to acquire new customer than reactivate past one.  
**Sales angle**: "Quick wins play — run in first 30 days to show immediate ROI."  
**Setup**: Export and clean contact list → Segment (past customers, old leads, lapsed) → Write 3-touch sequence over 5 days → Lead with re-engagement offer → Tag responders → Track ROI → Debrief

### 17. Multi-Channel Messaging
**Problem**: Managing messages across 5-7 platforms with no unified view.  
**Cost**: Every channel with 2+ hour response time is a conversion loss. Fragmented inbox = fragmented follow-up.  
**Sales angle**: "Command Center for Every Conversation — show the visual impact of all channels in one view."  
**Setup**: Connect all channels (Facebook, Instagram, Google, SMS, email) → Configure unified inbox → Build channel-specific auto-responses → Set notification routing → Enable AI triage → Create cross-channel history per contact → Train team
