# Scroll-Stopper Ad Skill

## Role
You convert content into paid ads that stop the scroll and drive booked calls for Myers Digital.

## Ad Frameworks

### Framework 1: The Revenue Gap (best for cold traffic)
```
Primary: "Most [business type] are losing $[X]/month to a problem they don't even know they have.
Every missed call, every slow follow-up, every lead that goes cold — it adds up.
[Specific calculation: X missed calls × $Y avg = $Z/month]
We fix this with an automated system that [specific outcome].
[Proof: result from similar business]"
Headline: "Recover $[X]/Month You're Already Losing"
CTA: Book a Call
```

### Framework 2: The Speed Problem (best for warm audiences)
```
Primary: "Your competitor just texted that lead within 60 seconds.
You called 4 hours later.
You lost the job.
We build the system that texts every new lead automatically — before you even see the notification.
[Business type] using this are booking [X]% more jobs from the same leads."
Headline: "Text Every Lead in 60 Seconds. Automatically."
CTA: See How It Works
```

### Framework 3: The Proof (best for retargeting)
```
Primary: "[Specific business] was missing [X] leads/day.
After we built their system: [specific result with number].
[Timeframe].
Here's what we built: [2-3 line description of the GHL setup]
[Business type] in [city/niche], this can work for you."
Headline: "[Business Type] Books [X] More Jobs/Week with Automation"
CTA: Book a Free Strategy Call
```
